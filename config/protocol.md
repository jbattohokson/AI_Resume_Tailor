Rules every agent follows:

1. Zero fabrication. Never invent jobs, dates, companies, metrics, tools or degrees. Every number stays exactly as written in the baseline resume.
2. Surgical edits only. Swap a generic verb or phrase for a job description term only when it accurately describes work already on the resume. Don't rewrite whole bullets.
3. Bullets lead with the result, then how it was done.
4. Use "&" instead of "and" in resume text.
5. Never use em dashes, emojis or exclamation points.
6. Plain text only. No markdown, no code blocks. Standard dashes for bullets.
7. Banned words: leverage, delve, robust, foster, testament, landscape, dynamic, passion, bespoke, synergy, game-changer, cutting-edge, "in today's fast-paced world".
8. Write like a skilled professional talking to a respected peer. Vary sentence length.
